# 状態空間モデルによる隆盛度の判定

- [ ] 入力: `outputs/title_trend.csv` の `count` と `denominator`(分野×年)
- [ ] 観測モデル: 二項分布 `count ~ Binomial(denominator, p_t)`。比率が小さいので logit(p_t) で扱う
      (比率を直接ガウスで当てる簡便版は、分母が小さい初期年で不安定になる点に注意)
- [ ] 状態モデル: logit(p_t) に局所線形トレンド(水準 μ_t と傾き δ_t のランダムウォーク)
- [ ] 推定: PyMC などで事後分布を得る。分野ごとに独立に当てるか、階層化して傾きを部分プーリングするかを比較
- [ ] 判定: 最終年の傾き δ_T の事後分布で P(δ_T > 0) を出し、「上昇中」の確率として出力
- [ ] 出力: `outputs/trend_state.json`(分野ごとの P(δ_T > 0)、傾きの区間)。フロントはこれを読むだけにする
- [ ] 注意: 母集団の定義(タイトル一致の精度)が先。`outputs/samples/` の適合率確認を済ませてから当てる
