# アブストの主題 / 前提 LLM 分類

- [ ] 発動条件: 精度検証サンプル(`outputs/samples/precision_samples.csv`)の適合率が低い分野があった場合のみ
- [ ] 入力: タイトル一致した論文のアブスト(`select=abstract_inverted_index` を復元)。取得量が増えるため費用を先に見積もる
- [ ] 判定: 「この語句が論文の主題か、前提として言及されただけか」の2値(+理由)
- [ ] 評価: 手でラベル付けしたサンプル(`label` 列)に対する一致率で LLM の判定を検証してから全体に適用
- [ ] 出力: 主題と判定された論文だけで数え直した比率を、タイトルのみの比率と並べて出す
